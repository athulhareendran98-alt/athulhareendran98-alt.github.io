# Athul Hareendran — Portfolio

A single-page portfolio designed for GitHub Pages.

## Folder structure

- `index.html` — the full website
- `media/` — replace the placeholder media with your own images/videos
- `README.md` — this guide

## Add your media

The current site intentionally uses visual placeholders so the layout can be built before the final photos are selected.

Recommended filenames:

- `media/dsc-hero.jpg`
- `media/dsc-01.jpg`
- `media/dsc-02.jpg`
- `media/coff-01.jpg`
- `media/coff-02.jpg`
- `media/football-action-01.jpg`
- `media/football-trial-01.jpg`
- `media/player-emotion-01.jpg`
- `media/player-portrait-01.jpg`

When replacing a placeholder, change the relevant `<div class="ph ...">...</div>` or `.media` block in `index.html` to an `<img src="media/your-file.jpg" alt="...">`.
